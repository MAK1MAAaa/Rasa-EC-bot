Recommendation
Safe write design

写操作的实现亮点：模型只能生成草稿，不能直接修改数据库

禁止路径

用户一句话触发模型直接创建订单、申请售后、取消订单或修改地址。

风险：权限绕过、状态错误、数据污染、现场演示不可恢复。

实际路径

模型只生成待确认草稿；用户确认后，后端重新校验并执行事务。

收益：自然语言入口保留，业务写入边界清晰。

Technical highlights

技术实现亮点集中在四个地方：混合路由、受控写入、真实卡片、可复现演示

Rasa

混合路由

Rasa 处理稳定流程，Agent 处理复杂理解和推荐解释。

Agent

受控写入

下单、售后、取消和地址修改都先生成 pending action。

API

卡片承接

推荐、订单、物流、售后都用结构化卡片承接客服结果。

Data

可复现演示

中文种子数据、本地图片和固定账号降低现场演示风险。

这些亮点的共同点是：把模型能力接入业务系统，但不把业务控制权交给模型。
